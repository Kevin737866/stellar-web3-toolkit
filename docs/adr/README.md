# Architecture Decision Records (ADR) Index

This directory contains Architecture Decision Records (ADRs) for the **Stellar Web3 Toolkit**. ADRs capture important architectural and design decisions, their context, and their rationale.

## ADR Status Legend

- **Proposed**: Under review and open for community feedback.
- **Accepted**: Approved and implemented in the codebase.
- **Deprecated**: Previously accepted decision that is no longer applicable.
- **Superseded**: Replaced by a newer decision (linked to the superseding ADR).

## How to Propose a New ADR

1. Copy the [ADR Template](template.md).
2. Assign the next sequential number (e.g. `0004-your-title.md`).
3. Fill out the **Context**, **Decision**, and **Consequences** sections.
4. Submit a Pull Request targeting the `docs/adr/` directory.
